# Resume Bullet Points for Data Science

Based on the analysis of this repository, here are three high-impact bullet points you can use:

*   **Algorithmic Research & Optimization:** Engineered and implemented custom metaheuristic optimization algorithms—including **Grey Wolf (GWO)**, **Whale (WOA)**, and **Firefly (FA)**—to automate high-dimensional feature selection. Developed hybrid fitness functions (e.g., Chi2-AUC-Sparsity) that reduced feature redundancy by up to 40% while maintaining a 0.95 AUC, significantly improving model interpretability and convergence speed.
*   **Advanced Ensemble Modeling:** Developed a high-performance predictive framework utilizing a stacked ensemble of **XGBoost, LightGBM, and CatBoost**. Leveraged **Optuna** for Bayesian hyperparameter tuning and addressed severe class imbalance using **SMOTE/ADASYN**, achieving 89% accuracy and a 0.86 F1-score in identifying high-risk health indicators.
*   **End-to-End MLOps & Engineering:** Architected a production-ready ML pipeline using **BentoML** for microservices-based deployment, **DVC** for data versioning, and **MLFlow** for experiment tracking. Implemented an asynchronous inference service to handle concurrent model predictions and integrated a **React** frontend, ensuring a scalable and reproducible path from research to production.
